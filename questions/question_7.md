## Detailed Competitor Profiles

### ServiceNow

| Dimension | Detail |
|-----------|--------|

| **Pricing Model** | Platform subscription; avg ACV >$400K; enterprise sales motion |
| **Target Segment** | Large enterprise (85% of Fortune 500) |
| **Sweet Spot** | Global enterprises with complex ITSM + ITOM + ESM needs |
| **Avoid When** | SMB/mid-market; budget-constrained; simple requirements |

### BMC Helix

| Dimension | Detail |
|-----------|--------|
| **Positioning** | Cognitive ITSM for multi-cloud enterprises; legacy modernization |
| **Pricing Model** | ~$115/user/mo; premium pricing; lengthy sales cycles |
| **Target Segment** | Large enterprise; global brands |
| **Sweet Spot** | Existing BMC customers; multi-cloud environments |
| **Avoid When** | Modern UX priority; quick deployment needed; SMB |

### Ivanti

| Dimension | Detail |
|-----------|--------|
| **Positioning** | Unified ITSM + Endpoint + Security platform |
| **Pricing Model** | Flexible per-user; cloud/on-prem/hybrid; custom pricing |
| **Target Segment** | Mid-market to enterprise; 88 of Fortune 100 |
| **Sweet Spot** | Organizations needing ITSM + endpoint management integration |
| **Avoid When** | Pure ITSM need; modern UX priority; transparent pricing wanted |

### Freshservice

| Dimension | Detail |
|-----------|--------|
| **Positioning** | Intelligent, right-sized, cloud-native ITSM; fast time-to-value |
| **Pricing Model** | $19-119/agent/mo; transparent; short sales cycle |
| **Target Segment** | SMB to mid-market; tech-forward organizations |
| **Sweet Spot** | Growing companies wanting modern UX without enterprise complexity |
| **Avoid When** | Deep customization needed; regulated industries (HIPAA unclear) |

### Jira Service Management

| Dimension | Detail |
|-----------|--------|

| **Pricing Model** | Free (3 agents) to $47+/agent/mo; consumption add-ons |
| **Target Segment** | DevOps-centric; tech companies; Atlassian shops |
| **Sweet Spot** | Organizations already using Jira Software; dev-IT collaboration |
| **Avoid When** | Non-technical ESM users; no existing Atlassian investment |

### ManageEngine

| Dimension | Detail |
|-----------|--------|
| **Positioning** | Comprehensive ITSM at affordable price; on-prem option |
| **Pricing Model** | $10-50/tech/mo; free for 5 techs; perpetual license available |
| **Target Segment** | Cost-conscious SMB; on-premises requirements |
| **Sweet Spot** | Extremely budget-constrained; regulated/air-gapped environments |
| **Avoid When** | Modern UX priority; cloud-first strategy; quick support needed |
