# Question 6: Who are the tier-2/emerging challengers (Freshservice, Jira Service Management, ManageEngine)?

## Answer

Tier-2 competitors are **direct competitors** to SolarWinds Service Desk — they target the same SMB/mid-market segment with similar pricing and positioning. Unlike tier-1 competitors (where the strategy is avoidance), tier-2 competitors require head-to-head competitive strategies.

---

## Tier-2 Competitor Overview

| Vendor | Customers | Target Segment | Starting Price | Differentiator |
|--------|-----------|----------------|----------------|----------------|
| **Freshservice** | 40,000+ | SMB to Mid-market | $19/agent/mo | Fast time-to-value, modern UX |
| **Jira Service Management** | Massive (Atlassian ecosystem) | DevOps-centric orgs | Free (3 agents) | Dev + IT integration |
| **ManageEngine** | 10,000+ | Cost-conscious SMB | $10/tech/mo (Free for 5) | Budget leader, on-prem option |
| **SolarWinds SD** | 5,100 | SMB to Mid-market | ~$19/agent/mo | HIPAA + ESM at accessible price |

## 1. Freshservice (Freshworks)

### Company Profile

| Metric | Value |
|--------|-------|
| **Parent Company** | Freshworks (NASDAQ: FRSH) |
| **Customers** | 40,000+ worldwide |
| **Target Segment** | SMB to mid-market |
| **Deployment** | Cloud-only |
| **Market Position** | Leading mid-market challenger |

### Positioning

Freshservice is positioned as the **"intelligent, right-sized, cloud-native"** ITSM solution emphasizing:
- Fast time-to-value
- Modern employee experience
- Lower cost of ownership
- Simplicity over complexity

> "Freshservice has helped us cut IT costs by 60% annually while improving service quality and speed." — Customer testimonial

### Pricing (2025)

| Plan | Price | Key Features |
|------|-------|--------------|
| **Starter** | $19/agent/mo | Incident mgmt, knowledge base, SLA, asset mgmt |
| **Growth** | $49/agent/mo | Service catalog, approval workflows, analytics |
| **Pro** | $95/agent/mo | Problem mgmt, change mgmt, project mgmt |
| **Enterprise** | $119/agent/mo | Sandbox, audit logs, IP whitelisting |
| **Day Passes** | $3/day | Occasional agent access |

**Free Trial:** 14 days with full feature access

### Key Features

| Category | Capabilities |
|----------|--------------|
| **Core ITSM** | Incident, Problem, Change, Release, Service Catalog |
| **Asset Management** | Hardware/software inventory, discovery |
| **AI/ML** | GenAI auto-triage, agent assistance, predictive SLAs |
| **Integrations** | 700+ marketplace integrations, MS Teams, Slack |
| **Automation** | 1,000 orchestrations/month (Starter) |
| **ESM** | HR, Facilities, and other department workflows |

### AI Capabilities (2025)

- GenAI for auto-triage
- Agent assistance
- Predictive SLAs
- Conversational self-service bots
- Low-code workflow editors

### Strengths

| Strength | Competitive Impact |
|----------|-------------------|
| **Modern UX** | Consistently praised for intuitive interface |
| **Fast deployment** | Quick time-to-value for mid-market |
| **Price/value** | Strong value perception vs. tier-1 |
| **Integrations** | 700+ integrations in marketplace |
| **AI investment** | Agentic AI embedded in platform |
| **Brand (Freshworks)** | Public company credibility |

### Weaknesses

| Weakness | SolarWinds Opportunity |
|----------|----------------------|
| **Reporting limitations** | Analytics could be more flexible |
| **Scale challenges** | Dashboard delays with large ticket volumes |
| **Customization depth** | Less customizable than enterprise tools |
| **HIPAA/Healthcare** | BAA availability unclear |

### Competitive Threat Level: **HIGH**

Freshservice is the most direct competitor:
- Same target market (SMB/mid-market)
- Similar pricing (~$19-119/agent/mo)
- Similar positioning (modern, cloud-native, easy)
- Larger customer base (40,000 vs. 5,100)
- Strong AI investment

## 2. Jira Service Management (Atlassian)

### Company Profile

| Metric | Value |
|--------|-------|
| **Parent Company** | Atlassian (NASDAQ: TEAM) |
| **Market Share** | ~8-10% (second largest) |
| **Target Segment** | DevOps-centric, tech companies |
| **Deployment** | Cloud, Data Center (self-managed) |
| **Market Position** | Leader for dev + IT integration |

### Positioning

JSM's differentiation is **deep integration with Jira Software** — making it the natural choice for organizations where:
- Development and IT ops collaborate closely
- DevOps practices are mature
- Atlassian tools (Jira, Confluence) already deployed

> "Analysts see Atlassian as a leader in the service management space given Jira Service Management's rapid growth and adoption for both ITSM and non-IT uses."

### Pricing (2025)

| Plan | Price | Key Features |
|------|-------|--------------|
| **Free** | $0 (3 agents) | Basic ITSM, 2GB storage, 100 emails/day |
| **Standard** | ~$20/agent/mo | Custom branding, unlimited portals, 250GB |
| **Premium** | $47-53/agent/mo | Assets (CMDB), AI, Virtual Agent, 99.9% SLA |
| **Enterprise** | Custom (201+ agents) | Analytics, multi-site, advanced security |

**Volume Discounts:** Per-agent cost decreases with team size

### October 2024 Pricing Changes

- Advanced incident, problem, and change management moved from Free/Standard to Premium/Enterprise
- 50,000 Assets objects included free in Premium/Enterprise
- Consumption-based pricing for Assets and Virtual Agent beyond limits

### Key Features

| Category | Capabilities |
|----------|--------------|
| **Core ITSM** | Incident, Problem, Change, Release, SLA |
| **Integration** | Native Jira Software integration (dev-ops) |
| **AI** | Atlassian Intelligence, Virtual Agent (Premium+) |
| **Assets** | CMDB included in Premium (50K objects free) |
| **Automation** | 500 rule runs/month (Free), unlimited (Enterprise) |
| **Templates** | ITSM, Customer Service, HR, Incident Mgmt |

### Strengths

| Strength | Competitive Impact |
|----------|-------------------|
| **Atlassian ecosystem** | Massive installed base of Jira users |
| **Dev-IT integration** | Unmatched for DevOps workflows |
| **Free tier** | Strong land-and-expand model |
| **Customizability** | Highly configurable for technical teams |
| **Modern interface** | Clean, intuitive for tech users |
| **Brand trust** | Atlassian is a known, trusted brand |

### Weaknesses

| Weakness | SolarWinds Opportunity |
|----------|----------------------|
| **Learning curve** | Complex for non-technical users |
| **Non-IT limitations** | Less suited for HR/Facilities ESM |
| **Pricing complexity** | Consumption-based adds can surprise |
| **Feature gating** | Key ITSM features now Premium-only |
| **Non-Atlassian orgs** | Less compelling without Jira Software |

### Competitive Threat Level: **MODERATE-HIGH**

JSM is a strong competitor but with a specific niche:
- Dominant where Jira Software is already used
- Less compelling for non-dev-centric organizations
- Free tier is powerful for land-and-expand
- Recent price/feature changes may frustrate some

## 3. ManageEngine ServiceDesk Plus (Zoho)

### Company Profile

| Metric | Value |
|--------|-------|
| **Parent Company** | Zoho Corporation |
| **Customers** | 10,000+ in 23 languages |
| **Target Segment** | Cost-conscious SMB |
| **Deployment** | Cloud AND on-premises |
| **Market Position** | Budget leader |

### Positioning

ManageEngine positions as the **budget-friendly, feature-rich** option:
- Lowest entry price in the market
- Free version for up to 5 technicians
- On-premises option (rare in modern ITSM)
- Strong in cost-conscious markets

### Pricing (2025)

| Edition | Price | Key Features |
|---------|-------|--------------|
| **Standard** | $10-13/tech/mo | Help desk, ticketing, SLA, reporting |
| **Professional** | ~$23/tech/mo | + Asset management, purchase/contracts |
| **Enterprise** | ~$50/tech/mo | + ITIL (Problem, Change, CMDB, Release, Projects) |

**Free Version:** Standard Edition free for up to 5 technicians — unlimited tickets and end users

**Licensing Options:**
- Annual subscription
- Perpetual license (one-time purchase)
- Cloud or on-premises at same price

### Key Features

| Category | Capabilities |
|----------|--------------|
| **Core ITSM** | Incident, Problem, Change, Release, Service Catalog |
| **Asset Management** | Hardware/software tracking, contracts |
| **Project Management** | Built-in project capabilities |
| **Automation** | Smart ticket routing, workflow rules |
| **AI** | Built-in AI (details limited) |
| **CMDB** | Configuration management (Enterprise) |

### Strengths

| Strength | Competitive Impact |
|----------|-------------------|
| **Price leader** | Lowest cost in market |
| **Free tier** | 5 technicians free — very generous |
| **On-premises option** | Unique for regulated/air-gapped environments |
| **Feature depth** | Mature ITSM suite with all modules |
| **Perpetual license** | One-time purchase option available |
| **Zoho ecosystem** | Integrates with Zoho suite |

### Weaknesses

| Weakness | SolarWinds Opportunity |
|----------|----------------------|
| **Complex onboarding** | Steeper learning curve |
| **Dated UX** | Interface less modern than competitors |
| **Support quality** | Some report slow support response |
| **Price increases** | Annual increase concerns |
| **Scaling costs** | Per-technician model gets expensive |

### Competitive Threat Level: **MODERATE**

ManageEngine competes primarily on price:
- Very strong for extremely cost-conscious buyers
- On-prem option is unique differentiator
- Less threat in cloud-first, UX-focused evaluations
- Free tier (5 techs) undercuts even Freshservice

## Strategic Implications

### Opportunities

1. **Healthcare vertical** — HIPAA + BAA is a clear differentiator vs. all tier-2
2. **ESM for non-technical** — Simpler than Jira SM for HR/Facilities teams
3. **Freshservice switchers** — Target customers hitting scale/reporting limits
4. **ManageEngine modernization** — Customers wanting modern UX, better support

### Threats

1. **Freshservice momentum** — 40,000 customers and growing; strong AI investment
2. **Jira SM free tier** — Powerful land-and-expand in dev-centric orgs
3. **ManageEngine pricing** — Hard to compete on pure price
4. **Feature parity pressure** — All competitors adding AI rapidly
