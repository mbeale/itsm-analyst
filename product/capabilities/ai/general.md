# AI Capabilities Overview

## 1. Executive Summary

**Elevator Pitch:** SolarWinds Service Desk incorporates both Traditional AI and Generative AI (GenAI) to enhance support operations across the entire service delivery chain — from end-user self-service to agent productivity to IT department efficiency.

**Value Proposition:**
- **Self-Service Improvement:** Virtual Agent and smart suggestions reduce incident volume
- **Agent Productivity:** AI-powered suggestions, summaries, and routing reduce manual effort
- **Operational Efficiency:** Reduced MTTR and improved ticket classification accuracy

---

## 2. AI Architecture

### Two AI Systems

| Type | Technology | Purpose |
|------|------------|---------|
| **Traditional AI** | Machine learning, pattern matching | Classification, routing, KB suggestions |
| **Generative AI (GenAI)** | Large language models (SolarWinds AI) | Content generation, summaries, draft responses |

### GenAI Identification
All GenAI-generated suggestions are marked with a **"Generated by AI" icon** to distinguish AI content from human-created content.

---

## 3. Traditional AI Features

### End-User Facing
| Feature | Description |
|---------|-------------|
| **KB Article Suggestions** | Suggests relevant knowledge base articles based on search keywords |
| **Service Catalog Suggestions** | Recommends appropriate catalog items during ticket creation |
| **Virtual Agent** | Mimics human interaction, learns through conversation, provides real-time responses |

### Agent Facing
| Feature | Description |
|---------|-------------|
| **Automatic Routing** | Routes incoming incidents to appropriate teams/agents |
| **Automatic Classification** | Categorizes tickets based on content analysis |
| **Smart Suggestions** | Provides agent recommendations through historical analysis |
| **Related Asset Suggestions** | Identifies potentially related assets |
| **Similar Incident Detection** | Surfaces similar past incidents for reference |

### Operational
| Feature | Description |
|---------|-------------|
| **Sentiment Analysis** | Identifies negative requester comments for escalation |
| **Misclassification Reduction** | Reduces human error in ticket categorization |

## 5. Data Privacy & Scope

### Tenant Isolation
> GenAI searches are **limited to the currently selected tenant account**; they are not and cannot be performed across other customer accounts.

### ESM Data Boundaries
For Enterprise Service Management customers, searches are **restricted to the specific service provider's tickets only** — maintaining strict data isolation between departments (IT, HR, Legal, etc.).

### Privacy Architecture

| Boundary | Enforcement |
|----------|-------------|
| **Cross-Customer** | Absolute — no data sharing between customer accounts |
| **Cross-Provider (ESM)** | Strict — each service provider's data is siloed |
| **Cross-Category** | Scoped — searches limited to defined category |

## 6. Benefits by Persona

### End Users
- Virtual Agent provides real-time responses
- Guided self-resolution reduces wait times
- Escalation to human agents when needed
- Consumer-grade interaction experience

### Agents
- Sentiment analysis flags negative comments for escalation
- Reduced ticket misclassification and human error
- Suggested KB articles, related assets, and similar incidents
- Draft responses and summaries reduce manual writing

### IT Departments
- Improved self-service adoption reduces incident volume
- Accelerated response times
- Reduced Mean Time To Resolution (MTTR)
- Consistent service quality across agent skill levels
